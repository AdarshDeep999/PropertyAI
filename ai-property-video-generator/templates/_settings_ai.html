Advanced

Keys live in a restricted server-side file (DPAPI-encrypted on Windows). They are never included in a page, an API response, or a log line.

A key supplied through the server environment is read-only here — change it in your .env and restart the app.

Script generation mode

Template mode is always available, never calls an API and never bills you.

Whichever mode you pick, the script is checked against the facts you entered — the film cannot invent a price, a bedroom count or a feature.
