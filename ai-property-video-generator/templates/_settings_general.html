Privacy and storage

  • Keys live in a restricted server-side file, shown only as a mask and never sent to the browser or written to a log.
  • Photos and videos are processed on this server and are not uploaded to a third party — unless narration or a script uses the provider you configured.
  • This studio is public by default. Anyone with the URL can create a film, so serve it over HTTPS and rotate keys if the URL is shared widely.
